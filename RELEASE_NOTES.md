# Even-Pilot 1.1.1

A small patch for clearer G2 activity and Windows tray updates.

- G2 consistently labels the input row **New prompt**, including in read-only sessions. Active agents in the selected session appear directly underneath in the native list. Count changes defer while browsing to preserve focus; expanded message reading is unchanged.
- Windows tray updates show download percentage and installation status, prevent overlapping update requests and refresh progress faster. Downloads, installation and errors stay in the tray without a browser detour.

Update the Windows/Linux companion, then upload/install `even-pilot-1.1.1.ehpk` separately in Even Hub. Companion updates do not update the phone package. Existing pairing, Watch and notification settings are retained; native terminals remain running.

Read-only Codex/Claude sessions still require a connector for remote input. Existing platform, Claude and physical-device limitations remain; see [setup](https://github.com/Liang-Chu/Even-Pilot#readme).
