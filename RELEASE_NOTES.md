# Even-Pilot 1.0.22

- Windows and Linux monitoring for Pi, Codex and Claude, with a shared phone / G2 interface and multi-computer session management.
- Daily update checks and new-version reminders. Disable automatic checks per computer; install explicitly from the Windows tray, management page or Linux CLI.
- Installer downloads are checked against GitHub's SHA-256 digest. Updates retain settings and native terminals, check backend health and restore the previous version on startup failure.
- Independent Glance notifications or server-to-server forwarding through a central sender.
- Linux pairing prints URL, key and a QR code, including over SSH. Phone sessions group by device and fold tool records; G2 hides disconnected sessions while retaining Watch.

Install the Windows EXE or Linux x64 .run, then upload even-pilot-1.0.22.ehpk to Even Hub. Windows binaries are unsigned; Claude support is experimental. G2 firmware behavior and real Glance delivery still require device testing.
